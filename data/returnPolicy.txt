CUSTOMER SUPPORT RETURN AND REFUND POLICY

1. Return Window
Customers can request a return within 7 days of delivery.

2. Wrong or Damaged Product
If a customer receives the wrong or damaged product, they can request a return or replacement within 7 days of delivery.

3. Refund Processing
After the returned product is received and inspected, an eligible refund is processed within 5-7 business days.

4. Order Information
Customers should provide their order ID so the support team can check their order details.

5. Late Delivery
Customers should provide their order ID to check the latest delivery status.

6. Important Rule
Never guarantee a refund or replacement before verifying the order and checking eligibility.
If a case cannot be resolved using this policy, escalate it to a human support agent.
